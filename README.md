# Find Your Gym

A responsive fitness-discovery website prototype for central Madrid, created with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — page structure and content
- `styles.css` — visual design and responsive layouts
- `script.js` — map, filters, studio details and saved spaces

## Run locally
Open `index.html` in a browser while connected to the internet. The interactive map uses Leaflet and OpenStreetMap tiles loaded from online CDNs.

## Publish with GitHub Pages
1. Create a public GitHub repository named `find-your-gym`.
2. Upload `index.html`, `styles.css`, `script.js` and this `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then Save.
6. Wait for GitHub Pages to publish the site. The URL should be `https://YOUR-USERNAME.github.io/find-your-gym/`.

## Important project note
The three studio listings are fictional demonstration entries with illustrative coordinates and prices. They are not verified businesses. Research and replace them with accurate studio names, addresses, coordinates, prices and class information before presenting the project as a real directory.

## Map and attribution
The map uses Leaflet (https://leafletjs.com/) and OpenStreetMap map tiles. Keep the visible OpenStreetMap attribution in the website. Tile use is subject to the OpenStreetMap Tile Usage Policy: https://operations.osmfoundation.org/policies/tiles/.

## Accessibility
The prototype includes labeled search and select controls, keyboard-focus styles, semantic landmarks, accessible button labels and responsive layouts. Continue testing keyboard navigation and mobile screen sizes as you refine it.

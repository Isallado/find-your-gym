# Find Your Gym — Madrid

**Find Your Gym** es una guía visual para descubrir gimnasios y estudios de movimiento en Madrid. Está pensada para personas que quieren comparar espacios según actividad, zona y presupuesto, y encontrar una opción que encaje con su estilo de vida.

## Funcionalidades

- Búsqueda en tiempo real por nombre, dirección, zona o actividad.
- Filtros por tipo de actividad, zona y presupuesto.
- 30 espacios fitness con dirección, actividad y precio orientativo.
- Mapa interactivo con marcadores personalizados mediante Leaflet.
- Sincronización entre tarjetas y marcadores del mapa.
- Enlaces a las webs oficiales disponibles y a indicaciones de Google Maps.
- Diseño adaptable a escritorio, tablet y móvil.
- Sección editorial con enlaces a contenido de bienestar y skincare.

## Tecnologías

- HTML5 para la estructura.
- CSS3 para identidad visual, composición y responsive design.
- JavaScript para datos, búsqueda, filtros y comportamiento interactivo.
- [Leaflet](https://leafletjs.com/) para el mapa.
- [OpenStreetMap](https://www.openstreetmap.org/) para los datos cartográficos.

## Cómo ejecutar el proyecto

1. Descarga o clona este repositorio.
2. Mantén `index.html`, `styles.css`, `script.js`, `gyms.js` y `favicon.svg` en la misma carpeta.
3. Abre `index.html` en el navegador o utiliza Live Server desde Visual Studio Code.
4. Para publicar el proyecto, activa GitHub Pages desde la configuración del repositorio.

## Datos y criterios

Las direcciones y enlaces se han recopilado de las páginas oficiales de los centros cuando estaban disponibles. Los precios que aparecen como aproximados u orientativos no deben interpretarse como tarifas garantizadas: pueden cambiar según el plan, la promoción o la frecuencia de clases. Se recomienda confirmar el precio directamente con cada centro antes de contratar.

El campo **zona** se utiliza para agrupar tanto barrios como distritos conocidos por los usuarios (por ejemplo, Malasaña, Justicia, Retiro o Chamberí). No pretende sustituir una clasificación administrativa oficial. Las coordenadas de los marcadores son aproximadas y sirven para orientar la exploración del mapa.
